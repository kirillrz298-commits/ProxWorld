# 🤖 Telegram-бот техподдержки сервера ProxGrief (Minecraft)

Полнофункциональная система технической поддержки игроков Minecraft-сервера **ProxGrief** с умным **ИИ-помощником** и продвинутой **системой тикетов** для операторов.

---

## 🌟 Возможности бота

### 1. 🏠 Главное меню и интерактивные разделы:
- 🔑 **Проблемы со входом**: сброс и восстановление пароля (`/changepassword`), ошибки сессии («Invalid session»), сервер не пингуется, правильные версии.
- 💎 **Донат и покупки**: задержки зачисления, проверка в игре (`/cart`), перенос доната, прямая ссылка на авто-донат магазин.
- 🔨 **Блокировки и наказания**: бан консолью/античитом, бан модератором, правила сервера, форма апелляции.
- ❓ **Частые вопросы (FAQ)**: как начать играть (`/register`, `/login`, `/rtp`), основные команды (`/spawn`, `/home`, `/clan`, `/ah`), правила грифа и приватов.
- 👨‍💻 **Связь с оператором**: удобное пошаговое создание тикета с выбором темы, указанием игрового никнейма и описанием проблемы.
- 🤖 **Задать вопрос ИИ**: прямой интеллектуальный диалог с нейросетью.
- 🎫 **Мой тикет**: статус текущего обращения игрока в реальном времени.

---

### 2. 🧠 ИИ-помощник (AI Assistant):
- Автоматически отвечает на вопросы игроков 24/7.
- Предоставляет полезные советы по решению любых технических и игровых проблем с сервером.
- Если проблема требует ручного вмешательства (пропал донат, подозрение на взлом, апелляция на бан), тактично предлагает кнопку **«👨‍💻 Связь с оператором»**.
- **Универсальное место под API-ключ**: поддерживает **любой** OpenAI-совместимый ключ (OpenAI GPT-4o-mini, Google Gemini, DeepSeek, OpenRouter, Groq и др.).
- **Умный Fallback**: если API-ключ не указан или временно недоступен, бот автоматически использует локальную базу знаний, не прерывая работу.

---

### 3. 🎫 Система тикетов для операторов:
- Игрок создаёт обращение с выбором категории и указанием никнейма.
- Операторы и администраторы моментально получают уведомление с карточкой обращения.
- Кнопки управления тикетом:
  - 🙋 **«Взять в работу»** — закрепляет тикет за оператором и уведомляет игрока.
  - ✍️ **«Ответить»** — оператор вводит ответ, и он мгновенно доставляется игроку в бот.
  - 📜 **«История сообщений»** — просмотр всей переписки по обращению.
  - ❌ **«Закрыть тикет»** — завершает обращение с уведомлением игрока.
- Двусторонняя связь: любые текстовые сообщения игрока автоматически пересылаются назначенному оператору.

---

### 4. ⚡ Админ-панель:
- Вход по команде `/admin` или по кнопке `⚡ Админ-панель` (только для авторизованных операторов/админов).
- 📋 Просмотр открытых тикетов, тикетов в работе и всех обращений с удобной постраничной пагинацией.
- 📊 **Статистика**:
  - Всего игроков в базе
  - Всего обращений
  - Открытых, в работе и закрытых
  - Количество тикетов за сегодняшний день
  - Список активных операторов
- 👥 **Управление операторами**:
  - Назначение новых операторов по Telegram ID прямо из интерфейса бота.
  - Снятие прав с оператора.

---

### 5. 🛠 Команды бота:
- `/start` — Запуск/перезапуск бота и открытие главного меню
- `/help` — Подробная справка по командам
- `/ticket` — Создать новое обращение
- `/close` — Закрыть своё текущее обращение (или `/close <id>` для операторов)
- `/reply <id> <текст>` — Быстрый ответ оператора на тикет
- `/admin` — Панель администратора
- `/stats` — Просмотр статистики службы поддержки

## 🚀 Установка и быстрый старт

### Шаг 1. Клонирование / открытие папки
Убедитесь, что вы находитесь в папке проекта:
```bash
cd "c:\Users\USER\Desktop\ProxGrief поддержка"
```

### Шаг 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 3. Настройка файла `.env`
Откройте файл `.env` в любом текстовом редакторе (например, Блокнот или VS Code) и укажите ваши данные:

```env
# 1. Токен вашего бота от @BotFather:
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ

# 2. Ваш числовой Telegram ID (узнать в боте @userinfobot):
ADMIN_IDS=123456789

# 3. ID группы поддержки для уведомлений (0 - если уведомления слать админам в ЛС):
SUPPORT_CHAT_ID=0

# 4. МЕСТО ДЛЯ API КЛЮЧА ИИ (OpenAI, Gemini, DeepSeek, OpenRouter и т.д.):
AI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxx

# 5. Адрес API (по умолчанию OpenAI):
AI_BASE_URL=https://api.openai.com/v1

# 6. Название модели:
AI_MODEL=gpt-4o-mini

# 7. Параметры вашего Minecraft-сервера:
SERVER_NAME=ProxGrief
SERVER_IP=mc.proxgrief.ru
SERVER_PORT=25565
SERVER_VERSIONS=1.16.5 - 1.20.4
SERVER_SITE=https://proxgrief.ru
SERVER_DONATE_URL=https://proxgrief.ru/donate
SERVER_RULES_URL=https://proxgrief.ru/rules
SERVER_VK_URL=https://vk.com/proxgrief
SERVER_DISCORD_URL=https://discord.gg/proxgrief
```

> 💡 **Как использовать Google Gemini через OpenAI-совместимый интерфейс:**
> - `AI_API_KEY`: ваш ключ из Google AI Studio
> - `AI_BASE_URL`: `https://generativelanguage.googleapis.com/v1beta/openai/`
> - `AI_MODEL`: `gemini-1.5-flash`
>
> 💡 **Как использовать DeepSeek:**
> - `AI_API_KEY`: ваш ключ с platform.deepseek.com
> - `AI_BASE_URL`: `https://api.deepseek.com/v1`
> - `AI_MODEL`: `deepseek-chat`

---

### Шаг 4. Запуск бота
```bash
python main.py
```

После запуска в консоли появится подтверждение авторизации:
```
[INFO] ProxGriefBot: ✅ Бот @YourBotUsername успешно авторизован и готов к работе!
[INFO] ProxGriefBot: 🎮 Сервер: ProxGrief | Админов в конфиге: 1
[INFO] ProxGriefBot: 🧠 ИИ-помощник подключен: модель gpt-4o-mini
```

## 🗂 Структура проекта

```
ProxGrief поддержка/
│
├── config.py             # Загрузка и валидация конфигурации из .env
├── database.py           # Асинхронная база данных SQLite (тикеты, переписки, операторы)
├── ai_helper.py          # Модуль ИИ-помощника с системным промптом под ProxGrief и fallback-базой
├── states.py             # Машины состояний (FSM) создания тикета, ответов и диалога с ИИ
├── main.py               # Точка входа, регистрация команд и поллинг
├── requirements.txt      # Список библиотек (aiogram, aiosqlite, openai, python-dotenv)
├── .env                  # Рабочий файл конфигурации и API ключей
├── .env.example          # Шаблон конфигурации с комментариями
│
├── keyboards/            # Модули клавиатур бота
│   ├── __init__.py
│   ├── main_menu.py      # Главное меню, разделы и inline-кнопки
│   ├── tickets.py        # Кнопки для тикетов игрока и операторов
│   └── admin.py          # Меню админ-панели и пагинация
│
└── handlers/             # Обработчики сообщений и событий
    ├── __init__.py
    ├── common.py         # Команды /start, /help, информация о сервере
    ├── categories.py     # Обработка разделов (Вход, Донат, Наказания, FAQ)
    ├── ai_dialog.py      # Интерактивный чат с ИИ-помощником
    ├── tickets.py        # Логика создания тикетов, чата и закрытия
    └── admin.py          # Функционал админ-панели и управление операторами
```

## 🔒 Безопасность и надёжность
- Доступ к командам `/admin`, `/reply`, `/stats` защищен проверкой ролей в базе данных и списком `ADMIN_IDS`.
- Переписки игроков и операторов надёжно сохраняются в локальной базе `bot_database.sqlite3`.
- Поддержка непрерывной работы 24/7 с автоматическим перехватом сетевых ошибок.
